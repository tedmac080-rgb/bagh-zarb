# باغ ضرب (Bagh Zarb)

بازی آموزشی فارسی برای یادگیری و تثبیت جدول ضرب دانش‌آموزان پایه چهارم.

## Prototype
Vertical Slice باغ سیب با معماری Godot 4، یادگیری تطبیقی، Mastery/Retention، ذخیره محلی و مسیر ساخت Android APK.

> Art rule: شهروز و شهرزاد خواهر و برادر و همراهان ثابت بازی هستند. در تمام Assetهای شهرزاد، موی سر باید کاملاً و بدون استثنا پوشیده باشد.
